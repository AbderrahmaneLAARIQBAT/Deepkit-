# DeepKit Documentation

Welcome to the DeepKit documentation.

DeepKit is an open-source machine learning library built from scratch
to provide implementations of common machine learning algorithms.

## Contents

- [Installation](installation.md)
- [Linear Regression](linear_regression.md)


## Philosophy

DeepKit is not intended to replace mature libraries such as scikit-learn.

The main goal is to understand how machine learning algorithms work
internally by implementing them from scratch.

## Status

DeepKit is currently under active development.
